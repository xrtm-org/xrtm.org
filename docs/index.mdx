# Start with the event-forecasting loop

XRTM is **AI for event forecasting**. If you are new here, the shortest honest
path is:

1. run your first forecast
2. inspect the evidence on disk
3. measure quality with benchmark and validation
4. expand into monitoring, history, and optional local-LLM workflows

> `xrtm.org` is the presentation layer for the ecosystem. Product behavior and run-artifact contracts live in [`xrtm-org/xrtm`](https://github.com/xrtm-org/xrtm), package APIs and source examples live in their owning repos, and schema/policy truth lives in [`xrtm-org/governance`](https://github.com/xrtm-org/governance).
