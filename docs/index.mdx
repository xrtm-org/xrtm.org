# Start with the shipped product path

XRTM is a **local-first forecasting and model-eval workbench**. If you are new here, the shortest honest path is:

1. run the provider-free local demo
2. inspect the generated run artifacts
3. browse the same run in the WebUI or TUI
4. choose the workflow that matches your role

- [Run the local demo](/docs/getting-started#3-run-your-first-local-demo)
