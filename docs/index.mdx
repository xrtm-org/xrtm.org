# Start

1. Read the [xrtm product README](https://github.com/xrtm-org/xrtm)
2. Follow [Getting started](/docs/getting-started)
3. Open the released WebUI shell, use `/start` for first-success or named workflow runs, `/operations` for profiles and monitor/cleanup controls, then `/workbench` for the guided clone → constrained safe edit → validate → run → compare flow
4. Continue with [Researcher / model-eval](/docs/workflows/researcher-model-eval)
