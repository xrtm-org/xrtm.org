# Start

1. Read the [xrtm product README](https://github.com/xrtm-org/xrtm)
2. Follow [Getting started](/docs/getting-started)
3. Open the released local WebUI shell—the same local forecasting cockpit with visible version/local-state trust cues—use `/start` for first-success or named workflow runs, `/operations` for profiles and monitor/cleanup controls, `/workbench` for guided safe workflow authoring, and `/playground` for the bounded exploratory sandbox: one custom question first, read-only step inspection, explicit save-back
4. Continue with [Researcher / model-eval](/docs/workflows/researcher-model-eval)
